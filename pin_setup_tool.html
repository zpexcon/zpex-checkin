ZPEX — Worker PIN Setup

Admin tool · Generate PIN hash for Workers list

사용 방법: 기존 직원은 SharePoint PINSalt 값을 그대로 붙여넣고 PIN만 입력하세요(PINHash만 갱신). 신규 직원은 "새 Salt 생성"으로 Salt를 만든 뒤 PIN을 입력하면 Salt/Hash 둘 다 나옵니다 — 둘 다 SharePoint Workers 리스트에 붙여넣으세요.
✓ 복사됨
1. 위 Salt/Hash 값 복사
2. SharePoint → Workers 리스트 → 해당 직원 행 편집
3. (신규 직원만) PINSalt 컬럼에 Salt 붙여넣기
4. PINHash 컬럼에 Hash 붙여넣기 → 저장
